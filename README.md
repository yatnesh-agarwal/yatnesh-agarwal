## Featured Projects

### AI Interview Prep — Voice-Based Mock Interview Platform
> Open-source AI platform for realistic, voice-driven technical interview practice

[![Repo](https://img.shields.io/badge/GitHub-Repository-181717?style=for-the-badge&logo=github)](https://github.com/god-coder23/AI_Interview_Prep)

- Voice-first interview flow — users speak answers directly through the browser microphone
- **Ollama (Llama 3)** drives question generation, follow-up decisions, and per-answer scoring
- **Whisper.cpp** handles accurate offline transcription of spoken responses
- **Kokoro-JS** provides text-to-speech playback for AI interviewer prompts
- Questions tailored from user's skills, tech stack, or a pasted job description
- Final session summary with an overall score and structured improvement feedback
- **MongoDB** persistence — sessions are saved and can be resumed at any time

`React` `Node.js` `MongoDB` `Ollama` `Tailwind CSS`

### SpendLens — AI Spend Audit for Startups
> Audits a startup's SaaS and AI tool subscriptions to surface overspending and downgrade opportunities

[![Live Demo](https://img.shields.io/badge/Live_Demo-spendlens.vercel.app-58a6ff?style=for-the-badge)](https://spendlens-steel.vercel.app)
[![Repo](https://img.shields.io/badge/GitHub-Repository-181717?style=for-the-badge&logo=github)](https://github.com/god-coder23/spendlens)

- **Gemini API** generates personalised audit summaries with specific downgrade recommendations
- Supports auditing ChatGPT, Claude, Cursor, GitHub Copilot, Windsurf, and OpenAI API spend
- **Firestore-backed** audit persistence with unique shareable audit URLs
- **GitHub Actions** CI pipeline with automated tests and linting on every push
- Designed as a dual-purpose product — useful tool and lead-gen asset for AI infrastructure resellers

`React` `Gemini API` `Firestore` `Tailwind CSS` `GitHub Actions`
